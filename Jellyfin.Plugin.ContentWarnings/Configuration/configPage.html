Content Warnings

Shows community content warnings from DoesTheDogDie.com on movie and series pages. Data is looked up on the server, cached, and shown with the required "Powered by DoesTheDogDie.com" attribution. The free API tier is for non-commercial use: 30 requests per minute, 5,000 per month (two requests per title).

API

Free key from your profile page on DoesTheDogDie.com (section API). It stays on the server.

Display

Off: only the number of warnings is visible until someone opens them. Every user can change this for themselves.
A topic is shown when it has at least this many "yes" votes and this share of all votes. Changing these needs no new lookups.

Cache and request budget

Titles from the last two years are refreshed four times as often, as they still collect votes.
The task "Fetch content warnings" (daily at 4:00) fills the cache ahead of time. 0 = only look up titles when someone opens them.
The task stops when fewer requests than this are left this month.

Tags (optional)

Selected topics are also written to the movies and series as tags, e.g. CW: a dog dies. Use them to block titles for a user (parental controls → blocked tags) or to filter in native apps. Tags are visible to everyone, so they are not spoiler-free. The scheduled task applies changes to all titles.

The topic list loads once a valid API key is saved.
